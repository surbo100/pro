GOOGLE 포토 · 업로드 전 검사

이 사진, 이미 포토에 있을까요?

포토의 비교용 목록과 현재 가진 사진을 대조합니다. 사진을 선택해도 파일은 이 브라우저 안에서만 읽습니다.

결과는 목록 조회 시점의 식별자 일치 여부입니다. 실시간 백업 상태나 클라우드 원본의 완전한 무결성을 보증하지 않습니다.

1. Google 포토 연결

포토 탭과 사진을 선택하면 최신 목록 조회부터 대조까지 이어집니다. JSON·CSV 파일을 따로 저장할 필요가 없습니다.

Google 포토 열기

자동 연결은 함께 제공된 Chrome·Edge 확장에서 사용할 수 있습니다. 파일로 연 화면에서는 목록을 직접 선택할 수 있습니다.

JSON·CSV 직접 가져오기

제공된 도구의 JSON 또는 Google Photos Toolkit의 metadata.csv를 선택하세요.

목록을 가져오는 방법
  1. Chrome 또는 Edge에 Tampermonkey를 설치하고, 함께 제공된 내보내기 스크립트를 새 사용자 스크립트로 등록합니다.
  2. Google 포토 웹사이트에서 사용할 계정을 선택합니다.
  3. 화면의 ‘비교용 목록’ 패널에서 계정을 확인하고 ‘목록 내보내기’를 누릅니다.
  4. 완료 후 받은 JSON 파일을 위에서 선택합니다. 사진 대신 목록만 저장됩니다.

내보내기는 비공식 웹 인터페이스를 사용합니다. 실제 Google 계정에서의 호환성 검증이 필요합니다. 로그아웃·오류로 중단된 목록에서는 미발견 판정을 보류합니다.

아직 목록을 조회하지 않았습니다.

2. 검사할 사진 선택

먼저 10개 정도로 확인하세요. 이 버전은 파일당 256 MiB까지 검사합니다. 더 큰 파일은 검사 오류로 표시합니다.

‘식별자 일치’는 같은 입력 파일로 등록됐다는 근거입니다. ‘목록에서 미발견’도 편집본·압축본·조회 이후 업로드를 배제하지 않습니다. 사진 삭제 전에는 별도 확인이 필요합니다.
