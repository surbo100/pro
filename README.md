# Google 포토 업로드 전 확인 — Windows PC · 0.3.0

선택한 PC 사진의 SHA-1을 Google 포토에 직접 조회하는 Chrome·Edge 확장입니다. 사진 원본을 업로드하거나 내려받지 않습니다. 파일명도 전송하지 않으며, 표준 Base64 SHA-1과 Google 포토의 기존 로그인 정보로 조회합니다. gpmc 인증 설정·별도 서버·전체 사진 목록·metadata.csv가 필요하지 않습니다.

## 다운로드 및 실행

1. 이 브랜치에서 **Code → Download ZIP**을 선택하고 압축을 풉니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. Google 포토에 로그인하고 확장 아이콘으로 검사 화면을 엽니다.
5. 계정과 사진을 선택한 뒤 **웹 해시 직접 조회**를 누릅니다.

기존 설치를 업데이트할 때는 새 ZIP으로 교체하고 확장 관리 화면의 새로고침을 누른 뒤 검사 화면을 다시 여세요. 버전은 0.3.0입니다. `Open.cmd`는 설치 안내를 엽니다.

## 결과의 의미

- **해시 일치**: 응답의 `hash`가 로컬 파일 SHA-1과 같습니다. 이름만 바꾼 동일 파일도 일치합니다.
- **조회에서 미발견**: 정상적으로 해석한 응답에서 해시를 찾지 못했습니다. 편집·압축본이 존재할 수 있으므로 미백업 확정은 아닙니다.
- **검사 오류**: 로그인·계정 변경·통신·응답 형식·파일 읽기 오류입니다. 미발견으로 처리하지 않습니다.

`dedupKey = SHA-1` 가정을 제거했습니다. 기존 JSON/CSV의 dedupKey 비교 화면은 제공하지 않습니다. 메타데이터 내보내기 스크립트는 참고용으로 남아 있으나 직접 조회에는 사용하지 않습니다.

20개 고유 해시씩 순차 조회하며, 동일 해시 파일은 한 번만 요청합니다. 파일당 256 MiB까지 지원합니다. 오류 시 이후 조회를 중단하고, 취소 후 미검사 파일은 판정하지 않습니다. 자동 업로드·삭제 기능은 없습니다.

## 검증과 한계

단위 테스트 및 Chromium의 모의 Google 응답 통합 시험을 통과했습니다. 실제 사용자 Google 계정과 Windows에서의 확장 설치는 미검증입니다. 비공식 웹 API이므로 Google 변경에 따라 작동하지 않을 수 있습니다. 처음에는 이미 백업한 원본, 이름만 바꾼 사본, 미백업 사진으로 확인하세요.

해시 일치는 원본 화질·현재 클라우드 파일의 바이트 무결성·휴지통 상태까지 검증하지 않습니다. 의미를 확인할 수 없는 null 응답은 안전하게 오류로 표시합니다.

구현 근거: [Toolkit 해시 조회 사례](https://github.com/xob0t/Google-Photos-Toolkit/issues/36), [API 소스](https://github.com/xob0t/Google-Photos-Toolkit/blob/main/src/api/api.ts). 사용 RPC는 `swbisb`, 요청은 `[hashes, null, 3, 0]`, 매칭 기준은 응답 `hash`입니다.
